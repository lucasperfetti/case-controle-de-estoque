"Quero fazer uma interface simples para uma aplicação de controle de estoque usando django + sqlite. os produtos precisam das seguintes informações:
- Identificação do produto,
- quantidade total,
- quantidade disponivel,
- quantidade reservada,
- quantidade bloqueada.
Funcionalidades do projeto:
- Entrada: Quantidade de produtos novos inseridos
- Saída: Quantidade de produtos retirados do estoque (apenas se tiver estoque disponível),
- Reservar: reservar quantidade desejada de um produto disponível para possível solicitação/pedido (a reserva deve ter uma identificação para posterior checagem),
- Bloquear: Bloquear certa quantidade de algum produto, tornando essas unidades indisponíveis para outras operações (deverá ter uma identificação para consulta e liberação posterior)
- Liberar: Permitir liberação de uma reserva ou bloqueio existente, retornando a respectiva quantidade disponível no estoque,
- Consultar: Consultar a situação atual de determinado produto, apresentando quantidade total, quantidade disponível, quantidade reservada e quantidade bloqueada"
